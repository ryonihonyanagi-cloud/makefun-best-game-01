NOVAFALL is an original neon arena-survival game: pilot a lone ship against escalating waves of geometric hunters, chain energy shards into score combos, and clear ten waves to win. It plays from static files in any desktop browser with keyboard and mouse, and a deterministic Node program hands it in.

## Run it

```sh
# The first line builds the entry into out/; the second serves the game at http://localhost:8080.
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```
